# PDF Report Summary

## 1. 这个报告主要讲的什么
这份《Global Startup Ecosystem Report 2021》主要评估全球创业生态系统在疫情冲击后的表现、复苏趋势和相对排名。报告结合 Startup Genome 的全球数据、创业者调查和生态系统方法论，比较不同城市与地区在融资、退出、人才、市场触达和连接度等维度的竞争力。前半部分聚焦全球创业经济、头部与新兴生态系统排名，以及重点子赛道的发展变化。后半部分按非洲、亚洲、欧洲、中东和北非、北美、大洋洲、拉丁美洲展开区域洞察，并配有大量城市生态系统页面。结尾部分则说明排名方法、数据来源、参考文献以及合作伙伴和致谢信息。

## 2. 从第几页到第几页讲到什么
