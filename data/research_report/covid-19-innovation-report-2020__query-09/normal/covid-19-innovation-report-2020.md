# PDF Report Summary

## 1. 这个报告主要讲的什么
这份《COVID-19 Innovation Report 2020》围绕新冠疫情暴发初期的全球创新响应，汇总了各国和各城市在疫苗、预防、诊断、治疗、资助支持和生活方式适应等方向上的创新项目。报告以 Coronavirus Innovation Map 为基础，构建了一套专门针对疫情创新的国家和城市排名。除了排行榜，它还通过国家案例页展示各地在疫情中的创新亮点。整体上，这是一份面向疫情早期全球创新应对格局的专题盘点。

## 2. 从第几页到第几页讲到什么
- 第 1 页到第 6 页：介绍 Coronavirus Innovation Map、数据来源、方法论和报告目标。
- 第 7 页到第 10 页：给出 COVID-19 创新国家与城市排名，并总结主要发现。
- 第 11 页到第 74 页：逐个国家展开案例介绍，展示各国有代表性的抗疫创新项目和特色方向。
- 第 75 页：版权与结尾信息。

## 2.5 所选对象

11-73页（国家总览页为奇数页），选对象为国家，所需数据为 Population、GDP Per Capita、Cities Rankings、以及六个 Number Of Sampled Innovations Per Category 指标
